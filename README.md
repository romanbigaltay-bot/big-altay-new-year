# 🎄 Большой Алтай · Новый год 2027 — лендинг

**Живой сайт:** https://romanbigaltay-bot.github.io/big-altay-new-year/

Одностраничный маркетинговый лендинг для кампании раннего бронирования новогоднего отдыха 2027 в Белокурихе (курорт «Большой Алтай», туроператор [big-altay.ru](https://big-altay.ru)). Санатории: «Белокуриха», «Сибирь», «Катунь». Цель страницы — конверсия посетителя в заявку: звонок **8 (800) 500-07-34** или заполнение формы с переходом в мессенджер MAX.

---

## 📌 Быстрый старт

Проект — чистая статика без сборки и зависимостей. Достаточно открыть `index.html` в браузере или запустить локальный сервер:

```bash
python3 -m http.server 8080 --directory .
# затем открыть http://localhost:8080
```

## 🗂 Структура проекта

```
.
├── index.html      — разметка лендинга (~1300 строк, все секции на одной странице)

├── AGENTS.md       — регламент работы AI-агента над проектом

```

## 🛠 Технологический стек

- **HTML5** — семантическая разметка, `lang="ru"`, OG-теги, aria-атрибуты, lazy-loading изображений.
- **CSS (vanilla)** — методология BEM, дизайн-токены в `:root`, три брейкпоинта: 1280 / 1024 / 640 px. Без фреймворков и препроцессоров.
- **JavaScript (vanilla ES6+)** — один файл, IIFE, самописные компоненты: анимация снега на Canvas (Retina-ready, IntersectionObserver), кастомные дропдауны, календарь, аккордеон, валидация формы. Ноль npm-зависимостей, ноль сборщиков.
- **Внешние ресурсы:** Google Fonts (Manrope, Nunito); изображения — jsDelivr CDN и big-altay.ru.
- **Деплой:** GitHub Pages, автодеплой при merge в `main`.

## 🔄 Рабочий процесс

1. Задача формулируется человеком.
2. Агент выполняет, прогоняет чек-лист верификации (`node --check`, валидность HTML, связность DOM-идентов, curl ресурсов).
3. Git-цикл: ветка `feat|fix|content|style|docs|chore/...` → коммит (Conventional Commits, описание на русском) → Pull Request → squash-merge в `main` → удаление ветки.
4. После merge обновляется live-сайт на GitHub Pages.
5. Полный отчёт в чате.

Полный регламент, стандарты кода и правила контента — в **[AGENTS.md](AGENTS.md)**.
